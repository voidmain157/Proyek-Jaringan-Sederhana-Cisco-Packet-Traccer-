# Proyek Jaringan Sederhana (Cisco Packet Tracer)

## Deskripsi
Simulasi jaringan LAN sederhana menggunakan 1 router, 1 switch, dan 4 PC.

## Topologi
- Router: R-Gateway
- Switch: SW-LAN
- 4 PC Client

## IP Addressing
- Router: 192.168.1.1
- PC1: 192.168.1.2
- PC2: 192.168.1.3
- PC3: 192.168.1.4
- PC4: 192.168.1.5

## Konfigurasi Router
- Interface: GigabitEthernet0/0/0
- IP: 192.168.1.1 /24
- Status: up

## Pengujian
- Ping antar PC berhasil
- Ping ke router berhasil

## Tools
- Cisco Packet Tracer

## Cara Menjalankan
1. Buka file .pkt
2. Jalankan simulasi
3. Gunakan ping untuk tes koneksi
